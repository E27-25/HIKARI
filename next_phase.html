🔬
Technique Choosing
Same model, smarter training methods
▾
  • Option A — Dynamic RAG-k ★ Recommended: model chooses k=0/1/3 based on uncertainty
  • Option B — Hard Negative Mining: inject visually similar but different-disease images
  • Option C — Multi-Reference Fusion: k=3 references, model attends to each differently
  • Option D — Self-Training: pseudo-label unlabeled images, expand dataset without manual cost
🧩
Pipeline Choosing
Add preprocessing steps around the model
▾
  • Option A — Segmentation-first ★ Recommended: SAM2 crops lesion → HIKARI classifies crop
  • Option B — Multi-lesion Detection: detect all lesions, classify each independently
  • Option C — Quality Filter: blur detection + skin crop + color normalization before inference
  • Option D — 3-Level Cascade: Group → Subgroup → Disease (add intermediate layer)
🔍
Explainability (XAI) Ready
Why did the model decide this? — clinically trustworthy
▾
  • GradCAM++ and Attention Rollout — sharper localization than Phase 1
  • Uncertainty score: confidence % shown with every prediction
  • Low confidence → "recommend dermatologist review" flag
  • Counterfactual: "if this region were removed, model predicts X"
  • Per-class activation atlas: visual signature for each of 23 diseases
📊
Evaluation Ready
One accuracy number is not enough for medical AI
▾
  • Per-subgroup accuracy: skin tone (Fitzpatrick I–VI), lesion size, body location
  • Calibration: reliability diagram + ECE — does 90% confidence = 90% accuracy?
  • OOD robustness: test on HAM10000, smartphone photos, noisy images
  • Clinical agreement: Cohen's Kappa vs real dermatologist diagnoses
  • Caption: add ROUGE-L, CIDEr, GPT-4o clinical relevance judge
🏥
Application After research
Make HIKARI usable without Python
▾
  • REST API: POST /diagnose → disease + confidence + caption + heatmap
  • Web UI: upload image, see diagnosis + GradCAM overlay instantly
  • Confidence threshold: auto-flag low-confidence cases for human review
  • Multilingual output: English + Thai clinical captions
